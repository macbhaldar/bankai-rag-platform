# Large Synthetic Banking Dataset

Synthetic-only corpus generated with seed 42. No real people, accounts, transactions, institutions or customer data.

Documents: 2,400
Customers: 10,000
Accounts: 2,000
Transactions: 50,000
Loans: 5,000
Securities: 3,000
QA pairs: 1,000
Retrieval queries: 500
Hard negatives: 100
Users: 500

Use QA train/validation/test for RAG evaluation and retrieval queries/relevance judgments for Recall@K, MRR and nDCG.
